# Code of conduct

RepoLens welcomes contributors with different backgrounds and levels of experience.

## Expectations

- Be respectful, constructive, and patient.
- Discuss code and ideas without personal attacks.
- Respect privacy, consent, and other people’s time.
- Accept feedback gracefully and help keep discussions focused.
- Make room for newcomers and different viewpoints.

Harassment, discrimination, threats, unwanted sexual attention, doxxing, and deliberate disruption are not acceptable. These expectations apply to issues, pull requests, discussions, and other project spaces.

## Reporting and enforcement

For platform abuse or an immediate privacy concern, use GitHub’s **Report abuse** tools. For non-sensitive project conduct concerns, contact maintainers through an available private project channel; if none is available, request one without posting identifying or sensitive details publicly.

Maintainers may remove inappropriate content, limit participation, or block accounts as needed. Responses should be proportionate to the behavior and prioritize participant safety. Reports should be handled discreetly; absolute confidentiality cannot be guaranteed.
