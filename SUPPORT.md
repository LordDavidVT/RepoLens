# Support

Start with [Getting started](docs/getting-started.md), the [User guide](docs/user-guide.md), and [Troubleshooting](docs/troubleshooting.md).

For a reproducible problem, open an issue using the bug-report template. For a proposed improvement, use the feature-request template. Include only redacted diagnostics and synthetic or public examples.

The project does not provide guaranteed support, hosted analytics, provider account support, or help bypassing repository access restrictions. GitHub/GitLab token permissions and organization policies must be handled with the relevant provider or administrator.

Use [SECURITY.md](SECURITY.md) for vulnerability reports.
