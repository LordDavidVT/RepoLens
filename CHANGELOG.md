# Changelog

Notable user-facing changes are recorded here. Versions follow [Semantic Versioning](https://semver.org/).

## 1.0.0

### Added

- Local GitHub and GitLab repository analysis with optional private-repository tokens.
- Full default-branch history, cached Git access, and asynchronous progress updates.
- Area/bar commit charts with daily, weekly, and monthly aggregation.
- Inclusive custom date ranges, recent-period presets, and merge exclusion.
- Contributor rankings, day/hour heatmaps, weekday totals, and file-type breakdowns.
- Repository metadata, CSV exports, and a responsive dark dashboard.
- Labeled synthetic demo data and a public demo screenshot.
- Offline tests, browser tests, CI, development guides, and source-release tooling.
