Behind the numbers

  • All commits reachable from the repository’s default branch are included, including merged branches. Unmerged branches are not counted.
  • Dates use committer timestamps in UTC; the start and end dates are inclusive. Empty time buckets are shown as zero.
  • Contributors are grouped by author email, with Git’s mailmap applied. Email addresses are not sent to the dashboard.
  • File types count tracked files at the latest analyzed revision. They are not lines of code and do not change with date filters.
  • GitHub’s open-issue count also includes open pull requests. API metadata may be unavailable when rate-limited or when token scopes are insufficient.
